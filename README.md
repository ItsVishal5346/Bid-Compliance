# BidSure AI

AI-Powered Integrated Bid Compliance Verification Platform for GeM Procurement.

This repository is intended for a frontend-only academic prototype built with React, Vite, TypeScript, and Tailwind CSS. The prototype uses fictional mock data and simulates bid intake, document handling, compliance reviews, risk indicators, reporting, and officer decisions. It is not an official GeM product and does not perform real OCR, AI verification, or procurement actions.
